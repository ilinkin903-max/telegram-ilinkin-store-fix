# v81.2 Database Compatibility Fix

Versi ini memperbaiki error `Could not find the table public.products in the schema cache` ketika source v79/v81 dipasang pada database yang sebelumnya menggunakan tabel `af_*`.

## Yang dilakukan migration
- Membuat seluruh tabel/fungsi yang dibutuhkan source v79/v81.
- Tidak menghapus tabel `af_*` atau data lama.
- Memindahkan `af_products` ke `products`.
- Memindahkan hanya `af_inventory_items` berstatus `available` ke stok produk baru.
- Produk `source_mode=prodseller` dipertahankan sebagai produk supplier ProdSeller.
- Memindahkan user dari `af_bot_users`.
- Memindahkan saldo dari `af_user_wallets` bila saldo pada sistem baru masih 0.
- Memuat ulang schema cache Supabase/PostgREST.

Jalankan `supabase/v81.2-database-compat.sql` satu kali melalui Supabase SQL Editor lalu redeploy Vercel.
