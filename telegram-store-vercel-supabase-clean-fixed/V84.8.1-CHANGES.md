# Link Auto Order v84.8.1

Rilis ini memperbaiki **Stok Bersama** dari panel sampai transaksi, sekaligus mengurangi waktu tunggu pada bot Telegram dan marketplace.

## Perbaikan Stok Bersama

- Nilai `stock_mode` sekarang dipertahankan saat data varian dinormalisasi dan disimpan. Pilihan **Shared** tidak lagi berubah atau hilang setelah penyimpanan.
- Varian dengan mode **Shared** membaca stok dari satu pool produk utama (`products.stock`).
- Setiap varian Shared menampilkan jumlah pool yang sama, tetapi total stok produk hanya menghitung pool tersebut satu kali.
- Varian **Separate** tetap memakai stok lokal miliknya sendiri.
- Stok lokal tersembunyi milik varian Shared tetap disimpan sebagai cadangan. Mengganti mode kembali ke Separate tidak menghapus stok lama.
- Pembayaran QRIS/gateway dan pembayaran saldo sekarang memakai aturan Shared yang sama.
- Pengambilan stok, pengurangan pool, penambahan angka terjual, pencatatan transaksi, dan pemotongan saldo dilakukan dalam transaksi database yang atomik.
- Dua pembelian yang datang bersamaan dikunci pada baris produk, sehingga item stok yang sama tidak dapat diberikan dua kali.

## Percepatan Bot Telegram

- Daftar produk bot memakai cache singkat dan menggabungkan request identik yang datang bersamaan.
- Pemilihan produk dan varian menggunakan hasil cache, sementara checkout terakhir tetap membaca produk dan stok secara langsung.
- Hasil penyimpanan pending order diteruskan langsung ke halaman konfirmasi sehingga tidak melakukan query ulang yang tidak perlu.
- Pengecekan lisensi paralel digabung menjadi satu rangkaian request.
- Request produk ProdSeller yang sama digabung agar tidak membebani supplier berulang kali.

## Percepatan Marketplace

- Katalog publik memakai cache singkat 5 detik.
- Saldo viewer memakai cache per pengguna selama 2,5 detik.
- Sinkronisasi profil pengguna dibatasi sekali per 30 detik pada instance yang sama.
- Katalog, sinkronisasi user, dan pembacaan saldo dijalankan paralel.
- Request supplier untuk tampilan katalog memakai batas waktu 1,5 detik dan dapat memakai snapshot terakhir yang tersimpan jika supplier sedang lambat.
- Validasi checkout, stok, harga supplier, dan saldo tetap dilakukan secara langsung agar transaksi tidak memakai data cache yang kedaluwarsa.
- Cache katalog hanya menyimpan data publik; data saldo tetap dipisahkan berdasarkan ID Telegram.

## Dashboard Manager

- Label sumber stok diperjelas menjadi **STOK BERSAMA** dan **STOK TERPISAH**.
- Input stok varian lokal otomatis disembunyikan saat Shared dipilih.
- Editor stok menampilkan pool bersama secara terpisah agar sumber stok lebih mudah dipahami.

## Database

File migrasi wajib untuk instalasi yang sudah berjalan:

`supabase/update-v84.8.1-shared-stock-speed.sql`

Migrasi tersebut:

- menormalisasi metadata `stock_mode` tanpa menghapus isi stok varian;
- mengganti fungsi `fulfill_paid_order_v62` dan `fulfill_wallet_order_v65` dengan implementasi Shared yang konsisten;
- dapat dijalankan berulang kali;
- tidak menghapus tabel, produk, transaksi, atau stok lokal varian;
- tetap membatasi eksekusi fungsi fulfillment kepada `service_role`.

Instalasi baru sudah mendapatkan fungsi yang sama melalui `supabase/schema.sql`.
