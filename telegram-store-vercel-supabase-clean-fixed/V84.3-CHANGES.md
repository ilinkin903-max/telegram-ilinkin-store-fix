# v84.3.0

- Workflow Reseller yang gagal atau supplier sedang busy langsung masuk `ATTENTION` dan berhenti.
- Tidak ada retry otomatis dari scheduler.
- `/api/workflow-runner` tidak lagi menjadwalkan ulang `WORKFLOW_BUSY`.
- Fulfillment/payment watcher tidak menjalankan workflow lagi jika run invoice tersebut sudah `ATTENTION`, `FAILED`, atau `CANCELED`.
- Notifikasi pembeli tetap idempotent per invoice.
- Retry dari dashboard, bila dipilih owner secara manual, tetap menggunakan invoice yang sama; bukan retry otomatis.
- Debit saldo supplier hanya dilakukan setelah hasil workflow berhasil diperoleh/disimpan sebagai delivered, dan RPC tetap idempotent per supplier + invoice.
