# V82.8 - Gemini Model Auto Discovery

- Tes koneksi Gemini sekarang mengambil daftar model langsung dari Google melalui `/v1beta/openai/models` menggunakan API key tersimpan.
- Model tidak lagi diasumsikan `gemini-2.5-flash`; sistem memilih model teks yang benar-benar tersedia untuk project/API key.
- Prioritas model: Gemini 3.7 Flash, 3.6 Flash, 3.5 Flash, Flash-Lite, lalu fallback model teks tersedia lainnya.
- Jika model tersimpan tidak tersedia, sistem otomatis mengganti dan menyimpan model yang tersedia lalu mencoba request kembali satu kali.
- Dashboard menambahkan tombol **Muat Model dari Google** dan datalist model diisi dari API key pengguna.
- Tes koneksi menampilkan model yang benar-benar dipakai.
- Default rekomendasi diperbarui ke `gemini-3.7-flash`.
- Tidak ada SQL baru.
