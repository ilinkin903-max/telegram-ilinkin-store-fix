# V82.8 Changes

- Added `response_mode` (`wait` / `same_message`) per reseller workflow step.
- Added `source_message_snapshot` to preserve the Telegram message used for button actions.
- Recorder automatically recognizes consecutive button clicks on the same message when the previous click produced no changed/new supplier message.
- Same-message workflow replay re-fetches the same Telegram message and clicks the next recorded button without waiting for a normal supplier response timeout.
- Dashboard shows an active source-message state and an editable response mode.
- Stock probe and normal order replay both support same-message button chains.
