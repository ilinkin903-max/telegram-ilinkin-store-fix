# v81.2.1 — SQL prerequisite fix

Perbaikan khusus migration `v81.2-database-compat.sql`.

## Masalah
Migration v81.2 langsung menjalankan bagian v69 yang menggunakan `products.delivery_mode` dan `po_orders`, tetapi prerequisite `update-v68-marketplace-po.sql` belum dibundel sebelumnya. Akibatnya SQL berhenti dengan error `column p.delivery_mode does not exist`.

## Perbaikan
v81.2.1 membundel migration v68 sebelum v69. Ini membuat:
- `products.delivery_mode`
- `transactions.delivery_mode`
- `transactions.delivery_status`
- `transactions.delivered_at`
- `transactions.delivered_by`
- `po_orders`
- fungsi PO v68 yang diperlukan sebagai prerequisite

Migration tetap tidak menghapus tabel `af_*` lama dan aman dijalankan ulang karena perubahan schema menggunakan `IF NOT EXISTS`, `CREATE OR REPLACE`, serta constraint dibangun ulang secara eksplisit.
