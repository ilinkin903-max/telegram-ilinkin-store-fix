# Link Auto Order v81.4

Perbaikan utama:

- Notifikasi order ke channel dibuat fail-safe. Lock notifikasi sekarang mempunyai fallback langsung ke tabel `job_locks` jika RPC Supabase belum terbaca schema cache.
- Notifikasi transaksi dikirim terpisah dari receipt pembeli dan dicoba ulang sampai 3 kali.
- Transaksi lama yang belum berhasil dinotifikasi dapat dipulihkan melalui `/api/payment-cron` atau tombol **Pulihkan Notif 30 Order** di Dashboard; lock mencegah duplikasi notifikasi yang sudah sukses.
- Order ProdSeller yang sudah delivered tetapi masuk melalui Retry Supplier juga mencoba kembali notifikasi channel.
- Hasil produk Telegram mendapatkan tombol `Salin Produk` (copy_text) untuk data sampai 256 karakter per item.
- `Nama Toko / Bot` dari Dashboard sekarang dipakai pada `/start`, gate wajib join, Marketplace, dan disinkronkan ke display name Telegram melalui `setMyName`. Username @bot tidak berubah.
- Tidak ada migration SQL baru.
