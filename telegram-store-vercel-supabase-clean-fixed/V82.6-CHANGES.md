# v82.6 - Google Gemini AI Flow Assistant

- AI Flow Assistant menggunakan Google Gemini sebagai provider default.
- Base URL otomatis: `https://generativelanguage.googleapis.com/v1beta/openai`.
- Backend otomatis memakai OpenAI-compatible Chat Completions.
- Model default `gemini-2.5-flash`, dengan saran `gemini-2.5-flash-lite` dan `gemini-3.6-flash`.
- Tombol langsung ke Google AI Studio untuk membuat API key.
- API key tetap disimpan terenkripsi server-side.
- Tidak memerlukan SQL baru.
- Seluruh fitur stok Telegram supplier dan flow Vinnstore v82.5 tetap dipertahankan.
