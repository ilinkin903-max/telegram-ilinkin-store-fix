# Link Auto Order v85.2.1 - Hapus Media Produk Otomatis di Bot

## Perubahan

- Bot Telegram **tidak lagi mengirim gambar/video produk** ketika user memilih produk atau memilih varian.
- Alur pemilihan tetap langsung menuju halaman konfirmasi order seperti sebelumnya.
- Tidak ada perubahan pada stok, harga, varian, redeem, QRIS, GoPay, ShopeePay, checkout, atau fulfillment.
- `image_url` dan `media_type` produk tetap disimpan dan tetap digunakan oleh Marketplace.
- Media `/start` dan broadcast gambar/video tetap tersedia.
- Media Hub Image2URL di dashboard tetap tersedia.

## Database

Tidak ada migrasi SQL baru untuk v85.2.1.

## Deploy

Jika v85.2.0 sudah berjalan, cukup deploy ZIP v85.2.1. Tidak perlu menjalankan SQL tambahan.
