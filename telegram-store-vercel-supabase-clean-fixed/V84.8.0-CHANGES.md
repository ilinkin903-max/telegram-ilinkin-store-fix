# v84.8.0

- Masked Telegram usernames in successful transaction notifications sent to the channel while keeping them recognizable.
- Replaced Marketplace workflow availability labels from “Otomatis” to the current stock quantity on product cards, detail badges, hints, and variants.
- Added a configurable **Nokos** button to the Telegram start menu. The manager accepts `@username`, a username without `@`, `t.me/...`, `telegram.me/...`, `tg://...`, or a full HTTP(S) URL.
- Positioned **Nokos** beside **Daftar Produk** when the product menu is enabled; it remains available as a standalone row in Marketplace-only mode.
- Renamed the menu button to **Saldo & Referral** without removing Top Up functionality from the wallet page.
- Changed **Cara Order** to the official Telegram `primary` button style (blue).
- Added regression tests for privacy masking, Nokos settings/routing, menu layout, stock labels, and release metadata.
