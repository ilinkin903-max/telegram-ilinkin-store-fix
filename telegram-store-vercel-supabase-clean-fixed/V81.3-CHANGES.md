# Link Auto Order v81.3

## Perbaikan

- Notifikasi transaksi berhasil kini dapat diatur dari Dashboard dan juga terkirim untuk order ProdSeller yang berhasil dikirim.
- Notifikasi transaksi memakai lock idempotent agar retry pembayaran tidak mengirim log channel berulang.
- Tambah pengaturan wajib join channel sebelum user dapat memakai bot.
- Bot memeriksa membership dengan Telegram `getChatMember`; owner dilewati agar tetap dapat melakukan maintenance.
- Tombol `Join Channel` + `Saya Sudah Join` tersedia pada layar pembatas.
- Link referral `/start ref_...` tetap dipertahankan ketika user harus join terlebih dahulu.
- Tambah pengaturan untuk menyembunyikan `Total User` dari menu `/start` tanpa menghapus statistik Dashboard.
- Tombol `Simpan Perubahan` edit produk pada HP diturunkan ke dekat bawah layar; navigasi bawah memang disembunyikan selama modal edit terbuka.
- Escape Telegram Markdown diperbaiki. Titik, minus, tanda seru, dan karakter MarkdownV2 lain tidak lagi diberi backslash saat bot menggunakan Markdown legacy.

## Setting baru di Dashboard → Pengaturan Toko

- Total User di Menu /start
- Wajib Join Channel
- ID / Username Channel Wajib Join
- Link Join Channel
- Notifikasi Transaksi
- Channel Notifikasi Transaksi
- Tes Notifikasi Channel
- Tes Cek Join Owner

## Catatan channel wajib join

Bot harus menjadi admin channel supaya `getChatMember` dapat memeriksa status user secara konsisten.

Untuk public channel, `ID / Username` dapat berupa `@channelanda`.
Untuk private channel, gunakan ID `-100...` dan isi `Link Join Channel` dengan invite link.

## Database

Tidak ada migration SQL baru. Setting baru disimpan di tabel `shop_settings` yang sudah ada.
