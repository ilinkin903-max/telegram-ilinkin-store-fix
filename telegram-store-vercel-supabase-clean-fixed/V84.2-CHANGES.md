# v84.2.0 Changes

- Workflow reseller error -> ATTENTION, stop immediately, no continuation.
- Buyer gets one idempotent failure notice per invoice.
- Manual restart starts from workflow Step 1 using the same marketplace sale/invoice.
- Supplier balance debit timestamp is preserved during restart to avoid duplicate debit.
- Revenue/profit live statistics use completed transactions only.
- COMPLETED -> CANCELED now removes the transaction's revenue/profit from statistics.
- CANCELED -> COMPLETED adds it back.
