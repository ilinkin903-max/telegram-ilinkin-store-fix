# v74 — Banner Ringkas, Swipe Marketplace, Cara Order Bot

- Submenu Banner sekarang menampilkan preview banner sebagai tampilan utama.
- Setiap banner memiliki tombol **Edit** dan **Posisi Banner**; form detail dan tombol hapus hanya muncul saat Edit dibuka.
- Posisi banner dapat dinaikkan/diturunkan melalui panel Posisi Banner.
- Preview banner bawaan ikut berubah saat teks, warna, dan posisi diedit.
- Slider Marketplace mendukung swipe/drag horizontal dengan jari, stylus, maupun mouse.
- Indikator titik slider dibuat lebih transparan agar tidak menutupi banner.
- Tombol Telegram dibedakan menjadi **Cara Order Bot** dan membuka panduan order khusus dari Bot Telegram.
