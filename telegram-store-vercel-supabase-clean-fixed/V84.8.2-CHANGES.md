# Link Auto Order v84.8.2 — Order Counter & Live Dashboard

## Statistik transaksi

- Counter semua-waktu atomik di database untuk order selesai, omzet, kuantitas, modal, dan profit.
- Revision transaksi untuk mendeteksi perubahan lintas instance Vercel.
- Ledger per invoice/ID untuk idempotensi dan perlindungan restore.
- Seed awal mempertahankan total historis dari `historical_stats` ketika detail lama sudah dibersihkan.
- RPC cepat `stats_summary_v84_8_2()`; total semua-waktu dibaca dari satu baris dan statistik hari/bulan hanya memindai transaksi bulan berjalan dalam zona waktu Asia/Jakarta.
- RPC fallback `stats_summary_v62()` diperbaiki agar hanya menghitung transaksi `completed`.

## Dashboard admin

- Endpoint `dashboard-live` untuk polling statistik ringan.
- Refresh otomatis setiap 5 detik, saat tab terlihat kembali, dan saat window fokus.
- Header no-store serta cache busting pada GET.
- Daftar order hanya dimuat ulang saat revision/jumlah berubah.
- Label kartu diperjelas menjadi **Total Order** dan omzet hari ini berasal dari ringkasan transaksi terbaru.

## Bot dan marketplace

- Cache statistik, produk, katalog, saldo, dan riwayat memakai revision.
- Perlindungan terhadap stale in-flight request setelah write.
- Invalidasi langsung setelah fulfillment baru, perubahan produk, perubahan setting, penyesuaian saldo, top up, koreksi transaksi, dan import backup.

## Laporan dan koreksi

- Rekap bulanan, analytics tujuh hari, deep stats, produk terlaris, dan statistik jam hanya memakai order `completed`.
- Pembatalan/pemulihan order memperbarui counter toko dan statistik user secara konsisten.
- Perubahan biaya/profit pada transaksi selesai otomatis ikut tercermin pada counter kanonik.

## Backup dan maintenance

- Import transaksi dengan invoice memakai `order_ref`, tanpa memaksa UUID sumber.
- Transaksi tanpa invoice memakai `id`.
- Rekonsiliasi counter setelah restore mencegah order lama dihitung ulang.
- Penghapusan detail transaksi lama menaikkan revision untuk menyegarkan daftar, tetapi tidak menurunkan total historis.
