# Link Auto Order v82.7.0

## Continuous Workflow Recorder

- Recorder sekarang tetap aktif pada step terakhir selama balasan belum dipilih/finalisasi.
- Dashboard melakukan long-poll pendek berulang ke chat bot supplier selama workflow masih `MODE REKAM`.
- Pesan sementara seperti `Loading`, `Sedang memproses`, atau `Sedang membuat produk` tetap disimpan walaupun kemudian dihapus oleh bot supplier.
- Jika bot supplier mengedit pesan dengan Telegram message ID yang sama, versi sebelumnya disimpan di `Riwayat perubahan pesan` dan versi terbaru tetap ditampilkan sebagai pesan utama.
- Setiap step menyimpan `recorder_before_snapshots`, yaitu keadaan chat sebelum aksi dijalankan. Baseline ini mencegah pesan lama supplier ikut dianggap sebagai balasan step baru.
- Request recorder lama melakukan pemeriksaan ulang sebelum menyimpan agar tidak menimpa step baru ketika admin sudah menekan tombol/kirim teks.

## Rekam Tombol Bertingkat

Alur berikut sekarang bisa direkam langsung tanpa harus menekan `Pilih Pesan Ini` setiap kali:

`Pilih Paket` → `Durasi` → `Jumlah 1/2/3/4/5` → `Konfirmasi` → `Hasil Produk`

- Menekan tombol supplier langsung mengunci pesan tempat tombol tersebut berada sebagai respons step sebelumnya.
- Jika admin melanjutkan dengan mengirim teks, recorder otomatis menggunakan pesan terakhir yang masih terlihat sebagai respons resmi step sebelumnya, tetapi seluruh pesan sementara tetap tersimpan dalam riwayat.
- Pesan yang sudah hilang dari chat ditandai `TERSIMPAN · SUDAH HILANG/BERUBAH`; tombol pada pesan yang sudah hilang tidak dapat diklik lagi.

## Keamanan dan Kompatibilitas

- Replay order tetap menggunakan response marker, timeout per-step, stok live, dan batas teks v82.4-v82.6.
- Tidak ada tabel atau data order/produk/saldo yang dihapus.
- Migration v82.7 hanya menambah satu kolom JSONB pada `reseller_workflow_steps`.
