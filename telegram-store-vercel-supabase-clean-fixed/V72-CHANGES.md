- Omzet grafik 7 hari dipindahkan tepat di atas masing-masing batang dan mengikuti tinggi batang.
- Bottom menu Reseller Dashboard dipusatkan pada desktop.
- Users desktop dibuat satu baris per user agar saldo, transaksi, spending, dan aksi tidak bertumpuk.
