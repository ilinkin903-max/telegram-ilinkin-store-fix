CATATAN LINGKUNGAN UJI
Registry NPM tidak dapat dijangkau dari lingkungan pemeriksaan karena kegagalan DNS. Agar seluruh test logika tetap dapat dijalankan, dependency test double lokal yang terisolasi digunakan untuk axios, dotenv, dan qrcode. Test double hanya berada di node_modules selama pemeriksaan, tidak mengubah package.json/package-lock.json, dan dihapus sebelum arsip rilis dibuat. Integrasi jaringan nyata tidak dipanggil oleh rangkaian unit/regression test ini.
