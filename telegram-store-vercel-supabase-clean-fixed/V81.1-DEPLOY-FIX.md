# Link Auto Order v81.1 — Deployment Fix

Perbaikan ini menangani error Vercel:

`The pattern "api/telegram.js" defined in functions doesn't match any Serverless Functions inside the api directory.`

## Perubahan

- Menghapus blok `functions` dari `vercel.json`. Vercel sekarang mendeteksi seluruh file `api/*.js` secara otomatis.
- Paket patch menyertakan **seluruh folder `api/`**, bukan hanya file API yang berubah.
- Route `/dashboard`, `/webhook`, dan pembayaran tetap sama.
- Tidak ada perubahan database dan tidak perlu menjalankan SQL baru.

## Struktur wajib di root GitHub

```
api/
lib/
public/
package.json
vercel.json
```

File berikut wajib ada langsung di root repository:

```
api/telegram.js
api/reseller.js
api/index.js
api/payment-webhook.js
api/payment-poll.js
```

Jangan upload folder pembungkus `link-auto-order-v81.1-patch/` sebagai satu folder ke repository. Upload **isi di dalamnya**.
