# Link Auto Order v85.1.0 — Plain Redeem + Image2URL Media Hub

## Perbaikan redeem

- Kode redeem sekarang dapat dikirim langsung sebagai pesan biasa tanpa `/redeem`.
- `/redeem KODE` dan tombol Redeem lama tetap berfungsi.
- Pengecekan kode polos dijalankan setelah flow input Top Up/Voucher agar nominal, voucher, atau teks flow aktif tidak salah dianggap sebagai redeem.
- Pesan biasa hanya diteruskan ke proses redeem jika formatnya valid dan kode tersebut benar-benar ditemukan di database.
- Seluruh proteksi v85.0.0 tetap dipakai: atomic claim, sekali pakai, anti-double redeem, timeout processing, dan order reference idempotent.

## Media Hub Image2URL

Dashboard owner sekarang memiliki menu **Media** / **Media Hub · Image2URL**.

- Upload gambar PNG/JPG/JPEG/GIF/WEBP langsung dari Dashboard ke Image2URL.
- Upload langsung divalidasi maksimal 2 MB dan diproxy melalui backend owner-only agar tidak bergantung pada CORS browser.
- Workspace `https://www.image2url.com/id/dashboard` tersedia di Media Hub.
- Workspace `https://www.image2url.com/id/video-to-url` tersedia untuk upload video, disertai tombol buka tab baru sebagai fallback jika iframe/login provider dibatasi browser.
- URL hasil Image2URL dapat dipreview, disalin/ditempel, lalu diterapkan ke:
  - produk baru;
  - produk yang sedang diedit;
  - broadcast;
  - media `/start`.

## Gambar & video produk

- Produk sekarang memiliki `media_type`: `image` atau `video`.
- URL media tetap disimpan pada `image_url` agar kompatibel dengan data lama.
- Marketplace menampilkan video pada kartu katalog, Flash Sale, dan detail produk bila `media_type=video`.
- Bot Telegram dapat mengirim video produk ketika user memilih produk/varian.
- Bot `/start` mendukung video.
- Broadcast owner mendukung video.
- Kegagalan Telegram mengambil media tidak menggagalkan checkout produk.

## Database / upgrade

Untuk database yang sudah ada, jalankan **sekali**:

`supabase/update-v85.1-media.sql`

Migration menambahkan `products.media_type` dengan default `image`, sehingga produk lama tetap kompatibel tanpa diedit ulang.

Untuk instalasi database baru, perubahan juga sudah digabungkan ke `supabase/schema.sql` dan compatibility SQL.

## Verifikasi

- Targeted redeem + media tests: **14/14 lulus**.
- Source JavaScript yang berubah dan seluruh file JS aplikasi lulus `node --check`.
- JavaScript browser Dashboard setelah HTML dirender juga lulus parse; tidak ditemukan duplicate DOM ID pada Media Hub.
- Selected UI regression: **55/58** lulus. Tiga test runtime tidak dapat dimulai karena source ZIP tidak menyertakan `node_modules` (`dotenv` / `axios`), bukan karena assertion regression.

## Urutan deploy

1. Jalankan `supabase/update-v85.1-media.sql` di Supabase SQL Editor.
2. Deploy source v85.1.0 ke Vercel.
3. Buka Dashboard → **Media** untuk upload/pilih URL media.
4. Produk lama tetap memakai gambar secara default. Untuk video, ubah `Media Produk` menjadi **Video** lalu masukkan URL HTTPS publik.
