# v82.1 — Browser Setup TG_STRING_SESSION

- Tambah halaman `/setup-userbot.html` untuk membuat `TG_STRING_SESSION` langsung dari browser.
- Alur: Setup Key → nomor Telegram → kirim OTP → masukkan OTP → 2FA bila aktif → Copy Session.
- Tambah endpoint server-side `/api/setup-userbot` dengan state login terenkripsi dan masa berlaku pendek.
- API ID/API Hash tetap hanya dibaca dari Vercel Environment Variables; halaman tidak menampilkan keduanya.
- OTP, password 2FA, dan session tidak disimpan ke Supabase/database.
- Tambah environment variable opsional `USERBOT_SETUP_KEY`; jika kosong fallback ke `WEBHOOK_SECRET`.
- CLI `npm run telegram:session` tetap tersedia sebagai alternatif.
