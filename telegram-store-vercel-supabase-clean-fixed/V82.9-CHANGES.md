# V82.9 - Bot Telegram Supplier Checkout Cache Fix

- Memperbaiki checkout bot yang memaksa verifikasi MTProto kedua pada tahap voucher/metode pembayaran walaupun stok supplier baru saja terdeteksi.
- Stok Telegram supplier yang masih fresh sekarang dipakai dari cache Supabase. Jika cache sudah stale, sistem mencoba refresh live; cache lama hanya dipakai dalam grace window terbatas.
- Produk Telegram/ProdSeller supplier tidak lagi diperiksa terhadap array stok lokal saat tombol Bayar dengan Saldo atau QRIS ditekan.
- Confirmation live stock menggunakan `force:false` agar tidak mengulang interaksi Telegram bila cache masih fresh.
- Verifikasi sesudah pembayaran/fulfillment tetap dipertahankan sebagai pengaman sebelum produk supplier benar-benar diambil.
- Tidak ada SQL baru.
