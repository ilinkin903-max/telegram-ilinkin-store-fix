v58 — Promo Khusus Flash Sale, Invoice Bersih, dan Submenu Rapi

Hasil: 55/55 pengujian berhasil.

Pemeriksaan mencakup:
- Sintaks JavaScript seluruh API, library, Marketplace, dashboard, dan script.
- Callback AutoGoPay probe tetap membalas HTTP 200 dan transaksi asli tetap wajib signature.
- Prefix AUTOGOPAY disembunyikan dari Invoice/Trx ID yang tampil, tanpa mengubah ID internal gateway.
- Promo yang dipilih untuk Flash Sale ditolak sebelum jadwal, setelah jadwal, atau ketika Flash Sale OFF.
- Promo biasa tetap dapat aktif di luar Flash Sale.
- Flash Sale tampil satu baris horizontal.
- Submenu Pengaturan dan Promo tampil satu baris horizontal tanpa ID HTML ganda.
- Promo/voucher produk dan varian, QRIS, Marketplace, serta notifikasi PESANAN SELESAI tetap lulus.

Catatan:
- Pengujian memakai stub dependency lokal tanpa jaringan. Dependency produksi di package.json/package-lock.json tidak diubah dan akan dipasang oleh Vercel.
- Transaksi AutoGoPay, Telegram, dan Supabase secara langsung tetap perlu diuji setelah deployment menggunakan kredensial aktif.
