v60 — AutoGoPay Callback, Modal Checkout, dan Profit

Hasil: 64/64 pengujian otomatis berhasil.

Pemeriksaan mencakup:
- Sintaks JavaScript seluruh API, library, Marketplace, dashboard, dan script.
- Probe callback AutoGoPay mendapat HTTP 200.
- URL verify v60 menerima payload verifikasi realistis tanpa signature.
- Transaksi asli dan transaksi dengan signature salah tetap ditolak.
- Prefix AUTOGOPAY disembunyikan dari Invoice/Trx ID tampilan.
- Modal default produk dan varian tersimpan.
- Modal dapat dikoreksi persis per checkout.
- Profit mendukung hasil positif maupun rugi/negatif.
- Alat Toko berada di dalam Pengaturan Toko.
- Promo Flash Sale, QRIS, Marketplace, dan notifikasi PESANAN SELESAI tetap lulus.

Catatan:
- Pengujian dependency memakai stub lokal tanpa jaringan; folder node_modules tidak disertakan dalam ZIP.
- Instalasi produksi tetap memakai package.json dan package-lock.json resmi.
- Transaksi AutoGoPay, Telegram, dan Supabase nyata perlu diuji setelah deployment dengan kredensial aktif.
