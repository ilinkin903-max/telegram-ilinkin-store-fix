# v71 — Classic UI + Bottom Navigation + Unified Marketplace

## Perubahan utama

- UI Reseller Dashboard dikembalikan ke gaya v69 (neo-brutalism klasik) dan bukan gaya 3D v70.
- Menu utama Reseller Dashboard sekarang menjadi dock tetap di bagian bawah pada desktop, tablet, dan HP.
- Dock tetap bisa digeser horizontal di layar kecil agar semua menu tetap mudah diakses.
- Floating Simpan Perubahan pada Edit Produk dinaikkan agar tidak tertutup menu bawah.
- Marketplace diselaraskan dengan bahasa visual Reseller Dashboard: border hitam tegas, shadow offset, kartu putih, aksen cerah, dan komponen ringkas.
- Marketplace tetap mempertahankan identitas biru untuk elemen utama/hero, tetapi bentuk komponen sama dengan dashboard.
- Navigasi Marketplace ditampilkan sebagai dock bawah pada desktop, tablet, dan HP.
- Tombol Pesanan/Panel di header Marketplace disembunyikan agar tidak dobel dengan menu bawah; saldo tetap tampil di header.
- Produk, Flash Sale, kategori, modal, QRIS, payment bubble, CS bubble, footer benefit, dan Telegram community card diselaraskan ke gaya yang sama.
- Tidak ada perubahan database atau SQL baru.
- Semua fungsi v69 (PO per varian, voucher preview, referral/saldo, pembayaran saldo, AutoGoPay, dan lainnya) tetap dipertahankan.
