# Update ke v82.5.0

1. Deploy seluruh source v82.5 ke Vercel.
2. Di Supabase SQL Editor jalankan `supabase/update-v82.5-workflow-boundary-rules.sql`.
3. Untuk workflow yang disalin ke produk berbeda, buka **Workflow → Buka → Edit** pada setiap step yang format balasannya berubah.
4. Sesuaikan **Penanda Teks Balasan Supplier**. Untuk step stok/hasil produk, sesuaikan juga **Teks Sebelum** dan **Teks Sesudah**.
5. Aktifkan kembali workflow setelah selesai diperiksa.

Tidak perlu merekam ulang seluruh workflow jika urutan tombol/perintah sama; cukup edit penanda pada step yang berbeda.
