# Link Auto Order v82.3.0

## Workflow Reseller
- Workflow dapat **Edit** dan **Salin**.
- Salinan membawa seluruh step, tombol/teks, pilihan pesan balasan, dan step hasil produk; salinan selalu dibuat sebagai DRAFT.
- Setiap step dapat diedit: jenis `Klik Tombol` / `Kirim Teks`, isi tombol/teks, serta kategori `Jumlah Pembelian` / `Teks Lainnya`.
- Step dapat dihapus dan urutan setelahnya otomatis dirapikan.
- Mengedit workflow/step yang aktif otomatis menonaktifkannya dahulu supaya order baru tidak membaca workflow setengah diedit. Aktifkan kembali setelah diperiksa.
- Produk yang mempunyai varian tetap dipilih langsung per varian pada `Produk yang Dituju`.

## Supplier / Reseller manual
- Supplier Telegram dikelola sebagai kartu ringkas: Supplier 1, Supplier 2, dst.
- Setiap kartu menampilkan saldo manual, jumlah varian, estimasi stok, tombol Produk, dan Edit.
- Saldo supplier **diinput manual** dan tidak dibaca dari bot supplier.
- Setiap workflow mempunyai `Modal Produk / Item`.
- Estimasi stok per workflow = `floor(Saldo Manual Supplier / Modal Produk)`.
- Ketika hasil order supplier berhasil didapat, `modal × jumlah` didebit satu kali secara idempotent dari saldo manual supplier, lalu stok semua workflow supplier tersebut dihitung ulang.
- Checkout dan runtime menolak order jika estimasi stok tidak mencukupi.
- Perubahan saldo manual dicatat di ledger supplier.
- Lock supplier dilepas setelah proses selesai; jika server crash, TTL tetap menjadi pengaman concurrency.

## UI
- Menu Supplier / Reseller memprioritaskan kartu supplier Telegram yang ringkas.
- ProdSeller tetap tersedia sebagai panel opsional/collapsible.
- Daftar Produk menampilkan stok workflow yang berasal dari perhitungan saldo/modal.
