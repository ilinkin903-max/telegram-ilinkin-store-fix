# Link Auto Order v84.5.0

## Fix: Hapus Workflow
Memperbaiki error:

`update or delete on table "reseller_workflows" violates foreign key constraint "reseller_workflow_runs_workflow_id_fkey"`

Saat workflow dihapus, source sekarang membersihkan child records terlebih dahulu:

1. `reseller_workflow_run_steps` berdasarkan `workflow_id`
2. `reseller_workflow_runs` berdasarkan `workflow_id`
3. baru `reseller_workflows`

Jika tabel history belum ada pada instalasi lama, cleanup tersebut dilewati dengan aman.

Jika database tetap menolak penghapusan, API tidak membocorkan nama constraint SQL dan mengembalikan pesan konflik yang aman.

## Data yang ikut/ tidak ikut terhapus

Riwayat run dan jurnal step milik workflow yang dihapus memang ikut dihapus, karena schema saat ini menggunakan foreign key `ON DELETE RESTRICT` ke workflow parent.

Transaksi/order marketplace, produk, saldo, stok, dan data user tidak ikut dihapus.
