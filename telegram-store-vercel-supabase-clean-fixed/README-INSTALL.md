# v72 — UI Polish

Versi ini melanjutkan v71 dan hanya mengubah UI/UX. Tidak ada SQL baru.

## Instalasi
1. Pastikan migrasi database sampai v69 yang Anda gunakan sudah terpasang.
2. Upload seluruh isi folder ini ke root repository GitHub.
3. Deploy ke Vercel Production tanpa build cache.
4. Buka `/reseller` dan marketplace untuk mengecek tampilan desktop, tablet, dan HP.

## Fokus perubahan
- Grafik omzet lebih mudah dibaca.
- Menu desktop center.
- Users desktop lebih rapi.
- Promo/voucher lebih ringkas.
- Marketplace header/search ikut scroll.
- Katalog tidak terlalu dekat dengan banner.
- Tombol close popup produk tetap terlihat saat scroll.
