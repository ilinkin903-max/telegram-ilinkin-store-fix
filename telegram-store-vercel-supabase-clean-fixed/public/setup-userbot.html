Setup Telegram Userbot

iLink.in Store · Vercel On-Demand Supplier

Gunakan akun Telegram khusus reseller. TG_STRING_SESSION adalah kredensial login penuh. Jangan kirim session ke siapa pun, jangan screenshot session, dan jangan simpan di GitHub.
Memeriksa…TG_API_ID / TG_API_HASH
Memeriksa…TG_STRING_SESSION

Masukkan hasil ini ke Vercel → Project → Settings → Environment Variables → TG_STRING_SESSION, Save, lalu Redeploy. Setelah itu Anda boleh menutup halaman ini.

  1. Pastikan TG_API_ID dan TG_API_HASH sudah ada di Vercel lalu Redeploy.
  2. Masukkan Setup Key dan nomor akun Telegram khusus reseller.
  3. Tekan Kirim kode Telegram, lalu cek pesan Telegram pada akun tersebut.
  4. Masukkan kode. Jika akun memakai 2FA, form password akan muncul otomatis.
  5. Copy session yang dihasilkan ke Environment Variable TG_STRING_SESSION.
Halaman setup tidak menyimpan OTP, password 2FA, atau session di browser.
