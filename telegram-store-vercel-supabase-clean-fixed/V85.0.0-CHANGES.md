# Link Auto Order v85.0.0 — Redeem Code

## Fitur baru

- Owner dapat membuat satu atau banyak kode redeem sekali pakai dari Dashboard **Redeem**.
- Setiap kode ditautkan ke satu produk tertentu. Jika produk memiliki varian, owner wajib memilih varian yang akan diterima user.
- Owner dapat mengatur jumlah item per kode, prefix kode, jumlah kode yang dibuat, dan tanggal kedaluwarsa opsional.
- Tombol **Redeem** berwarna hijau berada tepat di sebelah **Saldo & Referral** pada menu utama bot.
- User dapat menekan tombol Redeem lalu membalas kode, atau langsung memakai `/redeem KODE`.
- Redeem memakai jalur fulfillment yang sama dengan order normal sehingga mendukung stok otomatis, PO, ProdSeller, dan Telegram Workflow sesuai konfigurasi produk/varian.

## Keamanan & konsistensi

- Klaim kode dilakukan atomik di PostgreSQL dan setiap kode hanya dapat dipakai satu kali.
- Kode yang sedang diproses tidak dapat dinonaktifkan atau dihapus owner.
- Klaim macet dapat dilepas/diambil ulang setelah timeout 10 menit.
- Redeem tidak memotong saldo user dan tidak dianggap sebagai pembelian pertama untuk bonus referral.
- Kode yang sudah dipakai disimpan sebagai riwayat dan tidak dapat dihapus/digunakan ulang.
- Data redeem ikut masuk ke backup/restore aplikasi.

## Wajib saat upgrade

Jalankan `supabase/update-v85-redeem-codes.sql` **satu kali** melalui Supabase SQL Editor, kemudian deploy source v85.0.0. Untuk instalasi database baru, perubahan ini juga sudah digabungkan ke `supabase/schema.sql`.
